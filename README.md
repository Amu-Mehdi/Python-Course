# 🐍 Comprehensive Python Course

A structured, project-based Python course designed for absolute beginners, taking learners step-by-step from the fundamentals to an intermediate level.

**Instructor:** Mohammad Mahdi Ganji

---

## 📖 About This Course

This course is built around real, executable Jupyter Notebooks. Each lesson is a self-contained notebook that the learner can open, read, and run — without needing to stay connected to an AI chat. The chat is only for support and troubleshooting.

Every concept is taught in three clear perspectives:

1. **What am I telling the computer?** — The code itself.
2. **How does Python understand it?** — How the interpreter reads and executes the code.
3. **What actually happens?** — The visible output or change.

The course emphasizes **practice over theory** with a roughly 40% concept / 60% hands-on ratio.

## 📚 Curriculum Overview

### Part 1 — Python Basics (Lessons 01–05)

| # | Lesson | Topics |
|---|--------|--------|
| 01 | Introduction to Python | What is programming, what is Python, `print()`, comments |
| 02 | Variables | Creating, assigning, naming rules, reassignment |
| 03 | Data Types | `int`, `float`, `str`, `bool`, `type()`, type conversion |
| 04 | Input and Output | `input()`, `print()`, string-to-number conversion |
| 05 | Operators | Arithmetic, comparison, logical, assignment, precedence |

### Part 2 — Control Flow (Lessons 06–09)

| # | Lesson | Topics |
|---|--------|--------|
| 06 | Conditional Statements | `if`, `elif`, `else`, nested conditions |
| 07 | While Loop | Loop concept, conditions, counters, infinite loops |
| 08 | For Loop | `for`, `range()`, iterating over strings |
| 09 | Loop Control | `break`, `continue`, `pass` |

### Part 3 — Data Structures (Lessons 10–13)

| # | Lesson | Topics |
|---|--------|--------|
| 10 | Lists | Creation, indexing, mutation, methods, iteration |
| 11 | Tuples and Sets | Immutability, uniqueness, set operations |
| 12 | Dictionaries | Key-value pairs, methods, iteration |
| 13 | Nested Data | Lists in lists, dicts in dicts, real-world structures |

### Part 4 — Functions (Lessons 14–16)

| # | Lesson | Topics |
|---|--------|--------|
| 14 | Introduction to Functions | `def`, calling, reusability |
| 15 | Parameters and Return | Parameters, arguments, `return`, default values |
| 16 | Function Management | Scope, local/global, organizing code into functions |

### Part 5 — Practical Python (Lessons 17–20)

| # | Lesson | Topics |
|---|--------|--------|
| 17 | String Methods | Indexing, slicing, `lower`, `upper`, `split`, `join`, `f-strings` |
| 18 | File Handling | `open`, `read`, `write`, `with`, file modes |
| 19 | Exception Handling | `try`, `except`, `else`, `finally`, `raise` |
| 20 | Modules and OOP | `import`, built-in modules, classes, objects, `__init__`, `self` |

## 🏁 How to Use This Course

1. Clone or download this repository.
2. Open the lesson folder you want to study.
3. Open `lesson.ipynb` in Jupyter or VS Code.
4. Read each concept, run each code cell, complete each exercise.
5. Do not skip the exercises — they are the core of the course.
6. Move to the next lesson only after completing the current one.

```bash
git clone https://github.com/<your-username>/Python-Course.git
cd Python-Course
```
